# 其他算法题

## 二分插入排序：从 50 分到满分

练习日期：2026-10-03 · 专题：排序 / 二分查找 · 首次提交：50 分 · 修正后：满分

### 题目与基本思路

题目来源：[C 语言网 1715：数据结构—折半插入排序](https://www.dotcpp.com/oj/problem1715.html)。输入不超过 1000 个正整数，使用折半插入排序，输出升序序列。课程作业把这个改进算法记为 `ModInsertSort`，并要求分析最坏情况时间复杂度。

二分插入排序也叫折半插入排序。处理 `arr[i]` 时，前缀 `arr[0..i-1]` 已经有序；先在前缀中确定插入位置，再将后面的元素右移一格，最后放入当前元素。

本次丢分的关键在于：**找到位置之后是否结束本轮搜索，以及搜索区间为空时是否仍然执行插入。**

### 首次提交的错误代码（50 分）

下面保留第一次提交的完整程序，仅调整排版，并用注释标出两个出错的位置。原来的执行逻辑保持不变，后面的错误分析可以直接对照这份代码阅读。

```cpp
#include <iostream>
using namespace std;

void BinSertSort(int* arr, int n)
{
    for (int i = 1; i < n; i++)
    {
        int low = 0;
        int high = i - 1;
        while (low <= high)
        {
            int mid = (low + high) / 2;
            if (arr[mid] == arr[i])
            {
                int tmp = arr[i];
                for (int j = i - 1; j >= mid + 1; j--)
                {
                    arr[j + 1] = arr[j];
                }
                arr[mid + 1] = tmp;
                // 错误一：这里没有 break，也没有更新 low/high
            }
            else if (arr[mid] > arr[i])
            {
                if (low == high)
                {
                    int tmp = arr[i];
                    for (int j = i - 1; j >= mid; j--)
                    {
                        arr[j + 1] = arr[j];
                    }
                    arr[mid] = tmp;
                    break;
                }
                high = mid - 1;
            }
            else
            {
                if (low == high)
                {
                    int tmp = arr[i];
                    for (int j = i - 1; j >= mid + 1; j--)
                    {
                        arr[j + 1] = arr[j];
                    }
                    arr[mid + 1] = tmp;
                    break;
                }
                low = mid + 1;
            }
        }
        // 错误二：搜索区间变空时，没有在循环外按 low 补上插入
    }
}

int main()
{
    int n;
    cin >> n;
    int arr[n];
    for (int i = 0; i < n; i++)
    {
        cin >> arr[i];
    }

    BinSertSort(arr, n);

    for (int i = 0; i < n; i++)
    {
        if (i == n - 1)
        {
            cout << arr[i] << endl;
        }
        else
            cout << arr[i] << " ";
    }
    return 0;
}
```

### 错误一：相等分支完成插入后没有退出

原代码遇到 `arr[mid] == arr[i]` 时，已经将元素插入到 `mid + 1`，却没有 `break`，也没有更新 `low`、`high`。

最小反例：

```text
输入
2
1 1

预期输出
1 1
```

此时 `low = high = mid = 0`，插入之后数组仍是 `[1, 1]`。下一次循环的边界和比较值完全一样，又进入相等分支，因此一直循环。

修正是在相等分支的插入操作后结束本轮二分：

```cpp
arr[mid + 1] = tmp;
break;
```

这里的 `break` 结束的是内层 `while`，外层 `for` 随后处理下一个元素。

#### 为什么插入后继续比较还会弄乱数组

除了死循环，移动元素还可能覆盖 `arr[i]`。原版接下来继续使用 `arr[i]` 作比较，就会把另一个值误当成待插入元素。

例如原版处理 `[1, 2, 3, 1]` 时：

```text
待插入值为 1
第一次插入后：[1, 1, 2, 3]
此时 arr[i] 已经变成 3
继续搜索并再次插入后：[1, 3, 1, 2]
```

满分版本在插入后立即 `break`，不会再拿被覆盖的 `arr[i]` 进行比较。这份代码在移动前用 `tmp` 保存当前值，能够正确完成本轮插入。

### 错误二：只在 low == high 时插入，漏掉区间直接变空

原代码在大于、小于分支中，只在 `low == high` 时执行插入。但二分查找可能从多个候选位置直接跳到 `low > high`，不一定先经过 `low == high`。

最小反例：

```text
输入
3
2 3 1

预期输出
1 2 3

原版输出
2 3 1
```

插入最后一个 `1` 时的执行过程：

| 步骤 | low | high | mid | 结果 |
| --- | --- | --- | --- | --- |
| 开始搜索前缀 `[2, 3]` | 0 | 1 | 0 | `arr[0] > 1` |
| 执行 `high = mid - 1` | 0 | -1 | — | `low > high`，循环结束 |

循环结束后原版没有插入操作，所以最后的 `1` 留在原位。

修正是在 `while` 后补齐自然结束时的插入：

```cpp
if (low > high)
{
    int tmp = arr[i];
    for (int j = i - 1; j >= low; j--)
    {
        arr[j + 1] = arr[j];
    }
    arr[low] = tmp;
}
```

搜索区间为空时，`low` 就是插入位置。在这份实现中，没有提前遇到相等值时，`low` 左侧的元素都小于当前值，右侧的元素都大于当前值。

#### 为什么补插入不会执行两次

若在 `while` 内已经完成插入，就会执行 `break`。此时没有更新搜索边界，仍有 `low <= high`，因此外面的 `if (low > high)` 不成立。

若是更新边界后搜索区间变空，`while` 自然结束，才执行外面的补插入。因此每轮只插入一次。

### 满分实现

下面保留本次通过评测的排序函数，只调整排版并补充注释。

```cpp
void BinSertSort(int* arr, int n)
{
    for (int i = 1; i < n; i++)
    {
        int low = 0;
        int high = i - 1;

        while (low <= high)
        {
            int mid = (low + high) / 2;

            if (arr[mid] == arr[i])
            {
                int tmp = arr[i];
                for (int j = i - 1; j >= mid + 1; j--)
                {
                    arr[j + 1] = arr[j];
                }
                arr[mid + 1] = tmp;
                break;  // 已完成插入，结束本轮搜索
            }
            else if (arr[mid] > arr[i])
            {
                if (low == high)
                {
                    int tmp = arr[i];
                    for (int j = i - 1; j >= mid; j--)
                    {
                        arr[j + 1] = arr[j];
                    }
                    arr[mid] = tmp;
                    break;
                }
                high = mid - 1;
            }
            else
            {
                if (low == high)
                {
                    int tmp = arr[i];
                    for (int j = i - 1; j >= mid + 1; j--)
                    {
                        arr[j + 1] = arr[j];
                    }
                    arr[mid + 1] = tmp;
                    break;
                }
                low = mid + 1;
            }
        }

        // 二分自然结束时，按 low 补上插入
        if (low > high)
        {
            int tmp = arr[i];
            for (int j = i - 1; j >= low; j--)
            {
                arr[j + 1] = arr[j];
            }
            arr[low] = tmp;
        }
    }
}
```

### 更容易维护的写法

这次修正解决了原版的两个错误。后续实现同类问题时，可以把“找位置”和“移动插入”分开：提前保存 `x`，二分过程中只更新边界，结束后统一移动。这样只需要写一次移动循环。

```cpp
void BinSertSort(int* arr, int n)
{
    for (int i = 1; i < n; i++)
    {
        int x = arr[i];
        int low = 0;
        int high = i - 1;

        // 找第一个严格大于 x 的位置；没有则插在前缀末尾
        while (low <= high)
        {
            int mid = low + (high - low) / 2;
            if (arr[mid] <= x)
                low = mid + 1;
            else
                high = mid - 1;
        }

        for (int j = i - 1; j >= low; j--)
        {
            arr[j + 1] = arr[j];
        }
        arr[low] = x;
    }
}
```

这段代码搜索第一个严格大于 `x` 的位置，因此新元素会放在已有相等元素之后，保持稳定性。

### 最坏情况时间复杂度

二分查找减少了查找位置时的比较次数，但数组插入仍需要移动元素。

| 操作 | 第 i 轮的代价（i 从 1 开始） | 全部轮次的最坏代价 |
| --- | --- | --- |
| 二分查找插入位置 | `O(log(i + 1))` | `O(n log n)` |
| 为插入腾出位置 | 最多右移 `i` 个元素 | `Θ(n²)` |

在严格逆序数组中，每轮当前元素都要插到前缀开头，总右移次数为：

```text
1 + 2 + … + (n - 1) = n(n - 1) / 2
```

因此，二分插入排序的**最坏时间复杂度为 Θ(n²)**。排序函数只使用几个临时变量，额外空间复杂度为 `O(1)`。

分析这类算法时，需要把“找到位置”和“实际移动元素”的代价都算进去。

### 补充：满分实现与排序稳定性

稳定排序要求相等元素保持原来的相对顺序。只检查数值结果时，相等元素的顺序变化看不出来。

本次满分实现遇到相等值后，立即插入到 `mid + 1`，这个位置不一定在所有相等元素之后。给三个相等元素标上原始编号：

```text
输入：      [2_A, 2_B, 2_C]
插入 2_C 时，mid = 0，遇到 2_A 后立即插入
结果：      [2_A, 2_C, 2_B]
```

数值仍然有序，但 `2_B` 和 `2_C` 的相对顺序改变了。因此，本次满分实现不保证稳定性；上面的统一插入版本通过寻找第一个严格大于当前值的位置，可以保持稳定性。

### 自测与复习要点

| 输入数组 | 预期结果 | 主要检查内容 |
| --- | --- | --- |
| `[1]` | `[1]` | 外层循环不执行 |
| `[1, 1]` | `[1, 1]` | 相等分支是否退出 |
| `[2, 3, 1]` | `[1, 2, 3]` | 区间直接变空时是否插入 |
| `[1, 2, 3, 1]` | `[1, 1, 2, 3]` | 插入后是否继续使用变化后的 `arr[i]` |
| `[1, 2, 3, 4]` | `[1, 2, 3, 4]` | 插到前缀末尾的情况 |
| `[4, 3, 2, 1]` | `[1, 2, 3, 4]` | 每轮插到开头及最大移动量 |

这次练习可以记住三点：

1. 已经完成本轮任务的分支，要及时结束循环；继续执行的分支，要让搜索区间缩小。
2. 二分循环既可能因 `break` 结束，也可能因区间变空自然结束，两条路径都要检查。
3. 使用最小反例定位问题，分析复杂度时把比较和移动分别计算。
