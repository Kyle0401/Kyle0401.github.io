Google Test

记录 Google Test（gtest）的常用写法，包括测试用例、断言、测试夹具以及 CMake 集成。

C++ Google Test Unit Test 2026-09-29

1. Google Test 是什么

Google Test，通常简称 gtest，是 C++ 项目中常用的单元测试框架。测试代码通过 TEST、TEST_F 等宏组织，并使用 EXPECT_* 或 ASSERT_* 系列断言检查实际结果是否符合预期。

2. 最基本的测试

#include <gtest/gtest.h> int add(int a, int b) { return a + b; } TEST(AddTest, TwoPositiveNumbers) { EXPECT_EQ(add(1, 2), 3); }

TEST(AddTest, TwoPositiveNumbers) 中，第一个参数是测试套件名，第二个参数是测试名。

3. EXPECT 与 ASSERT

形式 失败后的行为
EXPECT_* 记录失败，但当前测试函数继续执行。
ASSERT_* 记录失败，并立即结束当前测试函数。
EXPECT_EQ(a, b); EXPECT_NE(a, b); EXPECT_TRUE(condition); EXPECT_FALSE(condition); ASSERT_EQ(a, b); ASSERT_NE(a, b);

4. 测试夹具 TEST_F

当多个测试需要共享初始化和清理逻辑时，可以定义继承自 ::testing::Test 的测试夹具，并在 SetUp()、TearDown() 中准备和清理测试环境。

class MyTest : public ::testing::Test { protected: void SetUp() override { value = 10; } int value; }; TEST_F(MyTest, InitialValue) { EXPECT_EQ(value, 10); }

5. CMake 集成

find_package(GTest REQUIRED) add_executable(my_test test.cpp) target_link_libraries(my_test PRIVATE GTest::gtest_main ) include(GoogleTest) gtest_discover_tests(my_test)
